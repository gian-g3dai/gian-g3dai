### Hi, I'm Gian

I work on **RL for LLM agents**, building a Python SDK of composable primitives for rewards, rollouts, and evals: one training loop, any agent plugged into it, basically a PyTorch for agents.

Background: co-founded **Unakin** (CTO), where I trained custom Llama models on our own A100 cluster and wrote Triton kernels to make it fit; before that, particle physics PhD at CERN. Previously a contributor to AppLE.py, pyg4ometry and BDSIM.

**Some things on here:**

- [LLM-Research](https://github.com/gian-g3dai/LLM-Research): Code Llama fine-tuning with PyTorch FSDP, CUDA-graph optimisation, and memory-efficient split cross-entropy
- [grpo-lab](https://github.com/gian-g3dai/grpo-lab): minimal GRPO training infra for small LLMs on GSM8K (TRL + LoRA), reproducible on an 8 GB GPU
- [Agentic-Workflows](https://github.com/gian-g3dai/Agentic-Workflows): Unakin's Visual Studio extension with LLM agents for chat, code search, test generation and more, inside the IDE
- [pyg4ometry](https://github.com/jairhul/pyg4ometry): open-source geometry library for HEP simulation (contributor)
