### About

- **Co-Founder & CTO at Unakin** — building AI coding agents, delivered as IDE plugins (including for Visual Studio) and used by 10 partner game studios and 200+ developers
- I architect the production multi-agent platform: **MCP orchestration**, async event-driven workflows, real-time APIs, and the evaluation & tracing frameworks that make agents measurably more reliable from live production feedback
- Under the hood: custom **LLM fine-tuning** (PyTorch FSDP / DDP / tensor parallelism), custom **Triton** GPU kernels, and distributed inference
- Built and led a **6-person engineering team**, raised **$1.5M**, and own technical strategy, architecture, and roadmap
- I like embedding with the teams I build for — mapping their workflows, shipping into production, and driving adoption
- Physics PhD (**Oxford / CERN**); core contributor to <a href="https://github.com/jairhul/pyg4ometry">pyg4ometry</a>, an open-source geometry library used across high-energy physics
